# Network Programming Lab

A curated collection of socket-programming exercises and Cisco Packet Tracer network designs.

The repository connects two sides of networking practice: implementing TCP/UDP communication in C and designing routed services and protocols in simulated networks. Original implementations and Packet Tracer files are retained with improved organization and validation.

## Contents

| Area | Exercises |
|---|---|
| Socket programming | TCP client/server, multi-client TCP, UDP client/server, and a `select`-based concurrent server |
| Packet Tracer | Static routing, dynamic routing, DHCP, OSPF, EIGRP, and an integrated routed/server network |

## Toolchains

- A POSIX environment with a C compiler for socket examples
- Cisco Packet Tracer for `.pkt` topology files

Each exercise retains its README, source, screenshots, and topology files where available.
